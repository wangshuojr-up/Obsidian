# 不订阅Claude，也能用上Opus？Kiro + 开源的 magpie

> 博主：西门菠萝吹牛 ｜ 抖音 ｜ 37 秒 ｜ 来源：口播转写（326 字）
>
> 一句话：两条不订阅 Claude 也能用 Opus 的路：亚马逊 Kiro 自带 Claude 模型；再用开源 Magpie 统一调度模型。

## 核心要点（来自口播）

1. Kiro：亚马逊官方的编程工具，订阅后直接带 Anthropic Claude 模型，Opus 也能选
2. 用 Kiro 不需要 Claude 账号，用 GitHub、Google 或亚马逊账号登录即可
3. Magpie：一个新的开源工具，把常用编程工具的模型收到一个地方统一管理
4. 在 Magpie 列表里点一下，就能指定哪个工具用哪个模型；每个请求发给了谁、用了多少 token 都看得清
5. 组合玩法：Kiro + Magpie，在 Claude Code 里也能用上 Opus
