# 总量收缩时，机会在品类里而不在总量里：五条筛选判据 + 三个自查

## 场景

要判断一个「大盘不再增长」的消费市场里还有没有生意可做，或者要给某个品类判断它还有没有空间。
触发条件：目标市场人均消费支出已见顶、或人口与收入预期同时下修。此时看行业总量、看人口增速，结论一定是「没得做」。

## 结论

先立一个口径：**性价比 = 感知价值 ÷ 价格**。分母和分子都能动，所以「追求性价比」不等于全线降价。

三条抬分子的路（价格不降反升）：
- 功能化：把品类卖点从口味换成可验证的功能（明治 PA-3 酸奶主打抑制尿酸）。
- 场景化：把同一个产品塞进新场景（RTD 从年轻人扩到佐餐、居家）。
- 品牌叙事：原料、工艺、产地（獭祭把清酒做成可送礼的高端品）。

一条压分母的路（就是你理解的「高端下放」）——**拆掉高端的成本结构，保留高端的体验**：
- 第三类啤酒：用税率更低的发泡酒工艺复刻啤酒口感 → 便宜的是税，不是味道。
- 萨莉亚：保留意式餐厅的菜品体验，砍掉现做、服务与选址成本。
- 速冻/预制菜：把外食的后厨搬进家庭冰箱，省的是人力与场地。
- PET 瓶茶饮：把茶馆的场景压成便利店 150 円。

所以准确的说法不是「高端品降价」，而是**参照系换锚**：大额消费（房、车）够不着，欲望就迁移到小额高频品类；在同一品类内部同时发生「高端下放」和「低端提价」，中间价位被挤空，形成哑铃结构。【主观判断，依据为报告中啤酒与清酒同页的分化数据】

五条可复用判据（按优先级）：
1. **看渗透率，不看人口。** 人少了，但「每户几台、每人几种」还能涨（日本空调户均约 3 台、洗碗机/新式吸尘器/面包机被称「令和三大件」）。
2. **场景延伸优先于人群扩张。** 人群是存量，场景是增量。
3. **涨价必须有理由。** 成本上行期，能给出功能/原料/品牌解释的品类才传导得出去，硬涨价的先死。
4. **性价比要做进机制里，不是做进折扣里。** 供应链、税率、SKU 结构、周转效率；靠补贴换来的低价不可持续。
5. **顺着人口与雇佣结构走。** 老龄化（成人纸尿裤、保健品、宠物）、非正式雇佣扩大（人力资源服务）是结构性的，不受景气影响。

三个自查（写方案前必须过一遍）：
- **幸存者偏差**：这类研究都是事后挑赢家，没有同期死掉的品类做分母；品类增速 ≠ 股东回报。
- **累计 ≠ 年化**：+195% 摊 29 年是年化 3.8%，跑赢的是萎缩的大盘，不是高增长。
- **不同构**：日本是「富而后老」，中国部分地区是「未富先老」，城镇化率、地产财富效应、电商渗透率都对不上，直接套品类会误判。

## 依据

日本 1992—2021 人均消费额变动（名义口径，较 1992 年）：

| 品类 | 变动 | 品类 | 变动 |
|---|---|---|---|
| 酸奶 | +195.1% | 酒类 | -15.0% |
| 速冻食品 | +178.2% | 酱油 | -46.0% |
| 碳酸饮料 | +148.2% | 清酒 | -52.7% |
| 奶酪 | +140.7% | 啤酒 | -62.1% |
| 茶饮 | +138.8% | 威士忌 | -64.7% |
| 预制菜 | +74.4% | 冰箱 | -42.8% |
| 饮料 | +71.4% | 服装 | -48.3% |
| 美容个护 | +51.7% | 家具 | -50.2% |

- 【事实】日本家庭消费支出 1992 年见顶；可选消费 1997 年见顶，此后 -16.4%。
- 【事实】必需消费品内部裂成两半：食品饮料整体仅 +6.1%，但乳制品 +19.6%、饮料 +71.4%、调味品 +23.6%，酒类 -15.0%。
- 【事实】逆势品类集中在「功能化 + 便利化」：酸奶、速冻、预制菜、碳酸、茶饮。
- 【事实】可选消费里唯一整体向上的板块是个护家清与美容（化妆品 +50.4%、美容仪器 +72.0%、家清 +57.0%），餐饮 +17.4%。
- 【事实】雇佣结构：正社员 38%、兼职 43%、派遣 4%、契约 8%、嘱托 4%，非正式雇佣近六成（该页对派遣/契约的文字说明疑似互换，引用时只用合计）。
- 【推测，置信度中】报告称要「寻找对中国消费行业的启示」，但 103 页里中国只出现两次（一张中日人均 GDP 对比图、一张旅游目的地表），中日映射实际没做，迁移必须自己做。

## 失效条件

- 目标市场没有经历资产价格下跌与收入预期下修（如仍处收入上行期），判据 1、2 的结论会偏保守。
- 品类渗透率已接近饱和（中国空调户均已超 1.5 台），「一户多机」的空间比日本当年小。
- 高通胀市场不适用名义口径，累计涨幅会被通胀放大。
- 只有品类数据、没有公司层面数据时，不能据此判断某家公司能赚钱——报告本身也不提供。
